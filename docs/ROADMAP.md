# План развития портфолио

Это план обучения для Junior DevOps / SRE. Пункты ниже не считаются реализованными навыками или выполненными проектами. Закрывайте их только после воспроизводимой проверки и добавления доказательств в репозиторий.

| Шаг | Практическая работа | Критерий готовности |
| --- | --- | --- |
| 1. Воспроизвести лабораторию | Запустить сервис и Prometheus, проверить тесты и правила, выполнить три отдельных сценария сбоя | Другой человек повторяет шаги из README; в репозитории есть заполненный учебный разбор с фактами |
| 2. Измерять доступность снаружи | Добавить синтетическую проверку `/api/work`, обнаружение отсутствия данных и недоступности самого мониторинга | Видны случаи отказа до приложения и исчезновения target; есть проверенный сценарий каждого сигнала |
| 3. Доставлять сигналы | Подключить Alertmanager и тестовый канал уведомлений, настроить группировку и подавление дублей | Пробный алерт доходит до канала, восстановление тоже видно; секреты хранятся вне Git |
| 4. Уточнить SLO | Собрать достаточную историю, настроить хранение и алерты расходования бюджета на нескольких окнах | Расчёты совпадают с тестовыми данными; низкий трафик и пропуски данных обработаны явно |
| 5. Сделать изменения проверяемыми | Дополнить CI проверкой образа и безопасным тестовым развёртыванием с откатом | Намеренно сломанная версия блокируется; предыдущая версия восстанавливается по инструкции |
| 6. Отработать Kubernetes | Перенести этот же сервис в локальный кластер, настроить probes, requests/limits и rolling update | Показаны перезапуск pod, обновление и откат; описаны отличия от Compose |
| 7. Описать инфраструктуру кодом | В отдельном проекте освоить Terraform для минимальной среды с контролем стоимости и удаления ресурсов | Есть читаемый plan, инструкция apply/destroy и подтверждённая очистка тестовых ресурсов |

Сейчас Kubernetes, Terraform, внешняя доступность, доставка уведомлений и production-эксплуатация не заявляются как реализованные части этой лаборатории. Следующий полезный результат — один полностью воспроизведённый сценарий с честным разбором, а затем расширение наблюдаемости.
