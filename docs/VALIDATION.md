# Проверка сборки портфолио

**Дата: 8 ноября 2026, Europe/Moscow.** Это автоматическая проверка локального учебного стенда при подготовке репозитория. Она не является результатом длительной эксплуатации или личным отчётом автора о пройденном упражнении.

| Проверка | Фактический результат |
| --- | --- |
| Unit-тесты сервиса | 8/8 успешно, включая запуск внутри образа Python 3.12 |
| `docker compose config --quiet` | Успешно |
| `promtool check config` | Конфигурация и 6 правил корректны |
| `promtool test rules` | 6 сценариев успешно: healthy, error, low-traffic error, down, latency, low-traffic latency |
| `make up` | Контейнеры запущены, demo healthy |
| `make smoke` | `/healthz`, `/readyz`, `/api/work`, `/metrics` отвечают по контракту |
| 40 запросов с ошибкой в каждом четвёртом | 30 ответов 200, 10 ответов 500, неожиданных ответов 0 |
| 8 запросов с `delay_ms=600` | 8 ответов 200, неожиданных ответов 0 |
| Данные, полученные Prometheus | `up{job="demo"}=1`; всего 49 операций, 10 ошибок, 8 операций дольше 500 ms |

49 операций включают один запрос из smoke-проверки. Для проверки медленных операций использовано выражение:

```promql
sum(demo_http_request_duration_seconds_count)
- sum(demo_http_request_duration_seconds_bucket{le="0.5"})
```

Состояния алертов и выдержка `for` проверены на синтетических временных рядах через promtool. Полный ручной цикл `pending → firing → inactive` оставлен в [runbook](RUNBOOK.md) для самостоятельной практики. Текущий результат GitHub Actions доступен по значку в README и во вкладке Actions.
